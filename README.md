# Police Kiosk 360

แอปพลิเคชัน Windows Forms ภาษา VB.NET สำหรับรับแจ้งเหตุจากประชาชนและคัดกรองเคสผ่านหน้าจอเจ้าหน้าที่ตำรวจ

## ความสามารถหลัก

- หน้าจอ Kiosk สำหรับเลือกประเภทและกรอกรายละเอียดเหตุ
- แยกระดับความเร่งด่วนของเคส
- หน้าจอเจ้าหน้าที่สำหรับค้นหา กรอง และรับเคส
- UI ภาษาไทย รองรับหน้าจอขนาดใหญ่และการสัมผัส

## การใช้งาน

ต้องติดตั้ง .NET 10 SDK บน Windows

```powershell
dotnet run --project Ball/Ball.vbproj
```
